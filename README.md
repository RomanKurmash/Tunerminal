# CLI Chromatic Guitar Tuner 🎸

Легковажний, високоточний хроматичний гітарний тюнер у реальному часі для терміналів Linux. Працює як напівпрозорий фоновий водяний знак (watermark), дозволяючи вам продовжувати вводити команди й бачити вивід терміналу паралельно з налаштуванням інструменту.

---

## Особливості

* 🖥️ **Фоновий режим (Watermark TUI):** Тюнер малюється прямо в активному вікні `/dev/tty` за допомогою ANSI-послідовностей. Він автоматично зберігає і відновлює позицію курсора, тому ви можете вільно друкувати.
* 🎯 **Центрування та масштабування:** Автоматично обчислює геометричний центр вікна. При зміні розміру вікна тюнер миттєво адаптується і стирає свої старі копії (вирішено проблему "привидів" та дублювання тексту при ресайзі).
* ⚡ **Нульова затримка (Zero Latency):** Захоплення звуку синхронізоване безпосередньо з аудіопотоком мікрофона, забезпечуючи миттєвий відгук без накопичення лагів.
* 🎶 **Підтримка різних строїв:** Можливість вибору одного з 4 строїв (E Standard, D Standard, Drop D, Drop C). Тюнер автоматично підсвічує номер поточної струни, яку ви налаштовуєте.
* 🌐 **Меню налаштувань (TUI):** Інтерактивне меню налаштувань мови (UA/EN) та строю (E Standard/D Standard/etc.) з підтримкою клавіш-стрілок і автооновленням.

## Вимоги до системи

1. **Go** (версії 1.18 або новішої).
2. **ALSA / arecord** (встановлено за замовчуванням у більшості Linux-дистрибутивів) для доступу до мікрофона.
   * *Для встановлення на Debian/Ubuntu:* `sudo apt install alsa-utils`

---

## Встановлення

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/yourusername/My-terminal.git
   cd My-terminal
   ```

2. Зберіть та встановіть бінарний файл:
   ```bash
   # Збирання проєкту
   go build -o ~/.local/bin/tuner
   ```

3. Переконайтеся, що шлях `~/.local/bin` додано до вашої змінної оточення `PATH`.

## Використання

Тюнер керується простими глобальними командами:

* **Запуск фонового тюнера:**
  ```bash
  tuner
  ```
  *(Тюнер з'явиться в центрі вашого поточного терміналу у вигляді напівпрозорого вікна. Ви можете продовжувати писати будь-які команди поверх нього)*.

* **Меню налаштувань (Інтерактивне TUI меню):**
  ```bash
  tuner settings
  ```
  *(Використовуйте стрілки **Вгору/Вниз** для навігації між опціями мови та строю, стрілки **Вліво/Вправо** для зміни значень, та **Enter** на пункті збереження. Фоновий тюнер автоматично призупиниться на цей час)*.

* **Повна зупинка тюнера:**
  ```bash
  stop tuner
  # або
  tuner stop
  ```
  *(Зупиняє процес демона та повністю очищає екран від графіки тюнера)*.

* **Запуск у передньому плані (для тестування/налагодження):**
  ```bash
  tuner foreground
  ```

* **Перевірка стану через CLI:**
  ```bash
  tuner status
  ```

## Як це працює зсередини (Технічні деталі)

1. **Інтеграція з терміналом:** Програма зчитує розмір терміналу безпосередньо з `/dev/tty` за допомогою системного виклику `ioctl(TIOCGWINSZ)`. Це дозволяє коректно визначати центр навіть тоді, коли демон запущено у фоні з перенаправленим `Stdin`.
2. **Очищення рефлоу (Reflow):** Під час зміни розміру вікна кнопкою максимізації, термінал переносить рядки. Тюнер зберігає попередній стан розмірів і вираховує математичний зсув старого малюнка відносно низу екрана, після чого точково затирає його, запобігаючи дублюванню.
3. **Механізм блокування (`tuner.pause`):** Інтерактивні команди створюють тимчасовий lock-файл `/tmp/tuner.pause`, який сигналізує фоновому процесу зупинити малювання на час взаємодії користувача з меню.
